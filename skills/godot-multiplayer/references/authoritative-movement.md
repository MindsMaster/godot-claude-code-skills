# 主机权威移动

引擎不提供预测和校正。本文列出自己实现时要守住的不变量。

## 基本循环

客户端按 tick 记录输入和结果，先本地模拟，再把输入发给主机。主机用同一个模拟函数跑输入，回传确认的 tick 和权威状态。客户端回到该 tick 的状态，重放之后未确认的输入。重放只重算可恢复的状态，不触发弹丸 音效 被动这类一次性效果。

## 不变量

| 不变量 | 破坏时的现象 |
|---|---|
| 校正带上全部影响位移的状态，包括击退和外力 | 主机击退时客户端没有外力，一次校正收敛不了 |
| 未确认队列溢出后，早于队首的校正要整体重置 | 只重放了溢出后的一小段，角色被拉回 |
| 传送要作废传送前发出的在途输入 | 主机落点偏移，每条在途 tick 偏一步 |
| 死亡时把本地位置对齐主机 | 尸体和相机停在错误位置 |
| 换房时移动状态在两端保持一致 | 冷却只有一端留着 |

## 输入

- 主机每批可能收到多条输入，只保留最新一条时中间的按下事件会丢
- 输入源只存当前按键状态时，一次轮询到达多批也会丢短按。只修上一条不够，在模拟里消费的输入要做按下锁存，读一次清一次

## 镜像插值

- 位置不变时不发数据的话，镜像停步后会先外插再回弹。60 Hz 下 5 m/s 外插 3 tick 时越过停步点 0.25 m，等下一份全量才弹回

## 周期全量

部分状态走增量时，发送计时要分开算。任意部分发送都重置全量计时的话，持续移动的实体永远等不到全量，其他状态只在变化时发一次。
